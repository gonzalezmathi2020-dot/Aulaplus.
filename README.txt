AULAPLUS — WEB DE ESTUDIO

Contenido:
- index.html: aplicación web.
- manifest.webmanifest y icon.svg: metadatos e icono para instalación PWA.
- sw.js: caché básica para uso sin conexión después de la primera carga.

USO LOCAL
1. Descomprime el ZIP.
2. Abre index.html en un navegador moderno.
3. Apuntes y agenda se guardan en el almacenamiento local de ese navegador.

PUBLICAR E INSTALAR
Para que el navegador permita instalarla como aplicación (PWA), publica los archivos de esta carpeta en un hosting con HTTPS. Luego abre la dirección web en Chrome o en el navegador compatible y usa "Instalar aplicación" o "Añadir a pantalla de inicio".

ASISTENTE CHATGPT
La web no accede automáticamente a tu cuenta de ChatGPT. El botón de consulta prepara un prompt, lo copia y abre ChatGPT en otra pestaña. Pega el texto en el chat. Así no necesitas una clave API ni colocar datos privados en la página.

DATOS
Los datos se almacenan localmente en el navegador del dispositivo. Usa "Exportar copia de seguridad" en el menú de escritorio para guardar una copia JSON. Borrar los datos del navegador puede eliminar los apuntes guardados.
